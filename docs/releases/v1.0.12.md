## 1. Executive Summary

Armaxcoin `v1.0.12` is a Public Testnet (`ARMX-TESTNET-1`) usability, synchronization-safety, mining-throughput, and security toolchain release delivering **Desktop Wallet GUI v2 (`armgui`)** with **`"Waiting for Sync"`** pre-sync mining protection, an **HTTP `503` Node Sync Gate** preventing unsynced peer bans, **integrated multi-thread CPU optimization** (`armaxhash.V2JobHasher` inline prefix caching and 64-byte padded worker slots across `core` and `miner`), encrypted Stratum TLS support (`stratum+ssl://` / `stratum+tls://`), additive node RPC pagination/telemetry endpoints, deterministic mining-job cancellation (`POST /mine/stop`), and Go `1.27.4` security remediation (`GO-2026-6859`)—all while preserving **100% rolling backward compatibility** with active `v1.0.11` nodes and miners on `ARMX-TESTNET-1` (zero Testnet consensus or activation-height changes).

## 2. Desktop Wallet GUI v2 (`armgui`)

1. **Pure-Go Embedded WebView2 Desktop Window (Windows) & Unified Web Backend (`gui/`):**
   - Replaced the legacy `lxn/walk` native widget toolkit with a pure-Go (`CGO_ENABLED=0`) Win32 window hosting Microsoft Edge WebView2 (`github.com/wailsapp/go-webview2 v1.0.23`), updating the Windows application manifest (`gui/armgui.exe.manifest` -> `1.0.12.0`) and embedded resource object (`gui/rsrc_windows_amd64.syso`).
   - Added Light and Dark (`armax_explorer`) visual themes, embedded brand icons (`gui/assets.go`), Convert menu UI placeholder, and an enlarged **Diagnostics** console with fixed `getmempoolinfo` querying `/mempool` instead of `/stats`.
2. **`"Waiting for Sync"` CPU Miner Queue & `v1.0.11` Fallback (`gui/server_app.go`, `gui/web_ui.go`):**
   - **Pre-Sync Anti-Ban Protection:** Clicking Start in the **CPU Miner** tab while the local node is still synchronizing queues the miner cleanly in **`"Waiting for Sync"`** mode (`#minerSyncBanner` progress banner, `"WAITING FOR SYNC"` status badge, and zero `POST /mine` requests dispatched while unsynced), preventing fresh nodes from mining and relaying behind-tip stale blocks that trigger public peer IP bans. Once `/stats` reports `synced: true`, mining starts automatically; clicking Stop during `"Waiting for Sync"` cancels cleanly without calling `/mine`.
   - **Additive Telemetry & Physical-Core Default:** `/api/mine/status` exports `waiting_for_sync`, `node_synced`, `node_syncing`, `local_height`, `best_peer_height`, `sync_progress`, `sync_reason`, and `optimal_threads` (auto-initializing `#txtMinerThreads` from physical CPU cores).
   - **Rolling `v1.0.11` Fallback Compatibility (`computeLegacyV1011SyncStatus`):** When connected to a `v1.0.11` daemon whose `/stats` response omits `"synced"`, `armgui` falls back cleanly—requiring `peers_active >= 1` on `testnet` while keeping `regtest` unblocked.
   - **Deterministic Stop & No Spurious `HTTP 409` Notices:** Stopping mining via the GUI issues `POST /mine/stop` (`CancelActiveMining`) and awaits worker termination cleanly, preventing background mining continuation or `HTTP 409` overlap errors upon rapid restarts (`TestCPUMiner_StopCancelsInFlightRPCAndRestartsCleanly`).
3. **Windows Minimize-to-System-Tray (`gui/native_window_windows.go`):**
   - Native pure-Go `Shell_NotifyIconW` integration (`winNotifyIconDataW` 976-byte 64-bit ABI, verified by `TestWindowsNotifyIconDataSize`).
   - Intercepts `WM_SYSCOMMAND` (`SC_MINIMIZE`) to hide the window (`SW_HIDE`) into the bottom-right Windows system tray so the embedded node, CPU miner, and 15-minute wallet auto-lock timer keep running uninterrupted (with a one-time informational balloon notice and safe fallback to standard taskbar minimize if tray registration fails).
   - Supports `"TaskbarCreated"` explorer-restart recovery, left-click / double-click restore with full WebView2 controller repaint (`Show`/`Resize`/`Focus`), right-click popup context menu (`Open Armaxcoin Wallet` / `Minimize to Tray`, non-blocking `Node` & `Miner` status line containing zero secrets/addresses, and `Exit Armaxcoin Wallet`), and guaranteed `NIM_DELETE` cleanup on shutdown.
4. **1-Click Embedded Node, Multi-Wallet Switcher & `bbolt` History Cache:**
   - Automatic embedded `armcoind` bootstrap when targeting an offline loopback RPC port (`gui/server_app.go`, cleanly stopped on exit before wallet zeroization and node shutdown).
   - 1-click **Multi-Wallet** management and switcher (`wallet/multiwallet.go`) keeping mnemonic/Argon2id AES-256-GCM encryption strictly client-side.
   - Local `bbolt` transaction history cache (`gui/history_store.go`, `gui/history_client.go`) incrementally synchronized via `GET /history?format=paged&min_height=...` and paired with an accurate ML-DSA-65 fee estimator (`gui/fee_estimator.go`).
5. **Security Boundaries & WSL Interop (`gui/server_app.go`, `gui/main_unix.go`):**
   - Strictly loopback-bound local HTTP server, single-use `/auth/launch` ticket & cookie on Linux/macOS or WebView2-injected `X-Armx-Launch-Auth` header on Windows, strict startup passphrase lock gate + 15-minute idle auto-lock (enforced even when minimized to tray), and CSP / `Origin` / `Sec-Fetch-Site` validation.
   - Automatically verifies POSIX `0600` writability (`isDirWritable`) on Unix/WSL and falls back cleanly from Windows-mounted WSL paths (`/mnt/*`) to `~/.config/ArmaxCoin`, alongside WSL host browser interop (`cmd.exe` / `powershell.exe` / `wslview`) and clear console `Launch URL` printing.

## 3. Standalone CPU Miner (`armminer`) & Integrated Multi-Thread Engine (`armaxhash/`, `core/`, `miner/`)

1. **Integrated Zero-Allocation Prefix Caching (`armaxhash.V2JobHasher`):**
   - Implemented stack-allocated value struct `V2JobHasher` (`NewV2JobHasher`, `UpdatePrefix`, `HashNonce`) using an inline `[768]byte` buffer to cache immutable Stage-1 ArmaxHash v2 prefix bytes across nonces (`0 B/op`, `0 allocs/op`, verified bit-identical to `HashV2` by `TestV2JobHasherBitIdentical`).
   - Integrated across `core.Blockchain.MineBlockContext`, `armminer` solo RPC mining, and Stratum v1 sessions, accelerating per-thread hashing while keeping consensus PoW digests unchanged.
2. **Cache-Line Padded Worker Slots, Sequential Nonces & Fast Cancellation (`core/blockchain.go`, `miner/miner.go`, `miner/cpu_optimizer.go`):**
   - Replaced shared atomic counters with 64-byte cache-line padded worker slots (`_ [56]byte`) and 1-second Sliding-EMA (`alpha = 0.3`) hashrate reporting, eliminating cross-core MESI cache-line false sharing.
   - Assigned workers contiguous positive `int64` nonce spans (`startNonce + int64(workerID)*(1<<36)`, incrementing `b.Nonce++`), preserving `v1.0.11` JSON IEEE-754 `< 2^53` integer serialization compatibility.
   - Replaced per-hash channel selects with cache-line-isolated atomic `stopState` checks (every 256 hashes on fast PoW, every hash on Argon2id v1), added lock-free `atomic.Pointer[stratumTargetSnap]` Stratum snapshots, and defaulted thread count to physical CPU cores (`GetOptimalCPUWorkerThreads`).
3. **Sync-Aware Mining & Encrypted Stratum TLS (`miner/miner.go`):**
   - Added `HTTP 503` sync-wait detection (`errNodeSyncing`) in `fetchBlockTemplate` and `runRemoteMiningLoop` so `armminer` pauses automatically while its node completes initial sync.
   - Added TLS 1.2+ transport support (`stratum+ssl://`, `stratum+tls://`, `ssl://`, `tls://`) in `dialStratumEndpoint` alongside existing `stratum+tcp://` pool connections and multi-endpoint failover (`TestParseStratumTLSPoolAddresses`).

## 5. Upgrading from `v1.0.11` to `v1.0.12`

`v1.0.12` shares identical consensus rules, nonce serialization compatibility (`< 2^53`), and storage formats with `v1.0.11`, enabling seamless rolling upgrades:

```bash
# 1. Stop running v1.0.11 daemon/miner/GUI gracefully (data directory in ./testnet/ or ~/.armax/testnet/ is preserved)
# 2. Download & verify v1.0.12 release artifacts (replace platform archive as appropriate)
curl -LO https://github.com/acxxcxx/armax-coin/releases/download/v1.0.12/armax-v1.0.12-linux-amd64.tar.gz
curl -LO https://github.com/acxxcxx/armax-coin/releases/download/v1.0.12/SHA256SUMS
curl -LO https://github.com/acxxcxx/armax-coin/releases/download/v1.0.12/SHA256SUMS.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

# 3. Extract and verify version
tar -xzf armax-v1.0.12-linux-amd64.tar.gz
./armcoind -version
./armgui -version
# Expected output: armcoind v1.0.12 / armgui v1.0.12
```
