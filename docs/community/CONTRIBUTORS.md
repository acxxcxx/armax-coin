# Armaxcoin Contributors

This document lists the contributors who have committed code or documentation to the Armaxcoin (`armax-coin`) repository, derived from Git history.

Contributions to Armaxcoin are voluntary open-source contributions under the MIT license. Contributor status itself does not offer tokens, airdrops, or financial compensation (separate from the preliminary Mainnet migration plan for verified external testnet miners, whose final ratio and terms remain TBA).
